This repository contains the data analysis summary for the study 'When AI Disappears: How People Experience and Respond to the Loss of AI Support' in submission to CHI 2027.

The study set out to inquire whether losing AI support is not the same as never having had it at
all. Real participants played a game in which they had to find their way through a maze. Some were
given hints towards the goal and then had those hints taken away midway through. Performance and behavorial metrics were collected from the experiment and analysed.

`analysis.html` contains a detailed flow of the analysis, models chosen for all outcomes and generates figures and visualisations.

### File Structure
```
analysis.html       details descriptiion of data, models fit and results and visualisations.
```
